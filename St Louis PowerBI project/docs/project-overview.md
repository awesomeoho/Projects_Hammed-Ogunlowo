# Project Overview

## Business Objective

Create a dashboard that helps job seekers understand the labor market for data roles by summarizing salary trends, job counts, skill demand, and locations.

## Key Questions

- Which job titles are most common?
- What is the median salary by role and region?
- What skills appear most frequently across postings?
- Where are the highest concentration of opportunities?
- How do work arrangements impact hiring patterns?

## KPI Ideas

- Total jobs
- Median yearly salary
- Median hourly salary
- Average skills per job
- Job count by title
- Salary comparison by title

## Data Sources

- Job posting dataset
- Optional location lookup table
- Optional skill taxonomy or normalization file

## Recommended Deliverables

- Cleaned Power Query dataset
- Star schema or simplified data model
- Overview dashboard page
- Detailed drill-through page
- Summary notes and screenshots
